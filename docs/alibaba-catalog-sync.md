# Alibaba 产品资料同步

## 来源与资料边界

- 店铺：`https://zjszsj.en.alibaba.com/`，浏览器显示语言 English。
- 分类保持来源的两级结构，包括空分类；不推测未标注的归属。
- 只导入逐条打开并核对过的详情：名称、属性、产品说明、图片、原始 FAQ、包装与交期。
- 来源价格仅标为批发参考价。导入不创建零售 SKU、库存、订单、销量、评分或访客数据，也不启用在线零售。
- 原始快照与来源 ID 保留在服务端，前台不暴露完整快照。

## 操作入口

1. 后台「产品管理」→「批量导入产品」。选择已核对的 JSON 资料包。
2. 分类先导入，产品逐条处理；管理员可选择发布。资料不完整时必须明确选择仅处理已核实部分。
3. 可以暂停，再次导入会跳过已存在的来源 ID，不覆盖运营修改，不自动恢复已删除产品或分类。
4. 每条结果可进入产品编辑，维护基本资料、分类、图库、参数和产品详情图片。
5. 产品删除为可恢复归档：从前台移除并停止零售，保留历史引用；恢复到草稿后重新审核发布。
6. 分类支持名称、地址、上下级、排序、显示开关。有关联内容或子分类时不能删除，需先调整归属；删除后可恢复但默认不启用。

## 采集与准备

`scripts/alibaba-browser-capture.mjs` 仅在已连接的浏览器中使用公开页面 DOM，逐条保存断点；遇到验证码交还用户完成，不绕过验证。

```sh
node scripts/prepare-alibaba-import.mjs --source-dir /path/to/capture
```

输入为 `catalog.json` 和 `details.json`，输出 `prepared-import.json`。完整采集与导入数量需以实际核验结果为准，不以资料包提交成功等同于全部导入成功。

`scripts/import-alibaba-catalog.mjs` 是可选的服务端凭据授权命令行入口；正常运营使用后台登录导入，不需要向浏览器提供服务端密钥。

## 安全与验证

- 沿用内容管理与发布权限、同源校验、请求大小限制和审计。
- 图片仅允许 Alibaba 公共图片 CDN，限制下载大小和像素，复制到自有媒体存储；以来源资源标识去重。
- 数据库迁移为 `20261016064307_product_catalog_sync.sql`，新增来源字段及分类父级，不修改 RLS 或权限授予。
- 自动回归：`pnpm test:product-upload`；覆盖身份、跨域、编辑者发布限制、可恢复删除、分类关联保护、不受信任图片来源等。测试不接触生产数据。
- 上线后应核对源/目标分类及产品数、参数、图片加载、分类筛选、详情页和后台编辑入口，并检查桌面与手机布局。
